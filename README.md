# 엑셀 정리기

## 쓰기 전에

1. **넣은 파일은 브라우저를 떠나지 않습니다.** 직접 확인하려면 F12 → Network 탭을 연 채로 파일을 넣고 정리해 보세요. 화면·처방 파일을 *받아 오는* 요청만 보이고, 무언가를 *보내는* 요청은 없습니다.
2. **이 정리기가 못 하는 것:** 빈칸(고객사·금액·제품구분)은 채우지도 표시하지도 않습니다. 입금일이 발행일보다 앞선 행도 잡지 못합니다.
3. **처방을 바꾸려면 `rules/`의 파일을 고칩니다.** 코드(`app.js` · `clean.js`)에는 처방이 없습니다.

## 쓰는 법

1. 화면에 엑셀(.xlsx · .csv)을 끌어다 놓습니다.
2. 파일 이름과 같은 처방(`rules/<파일 이름>.json`)을 찾아 보여 줍니다. 처방이 없으면 처방 파일을 직접 골라 올립니다.
3. «규칙대로 정리»를 누르면 행 수 변화 · 지운 행 · 고친 값 · 표시한 행이 나옵니다.
4. 정리본과 바꾼 기록을 내려받습니다(.xlsx 또는 한글이 깨지지 않는 .csv).

모르는 값은 지어내지 않습니다. 고치지 않고 `_표시` 칸에 까닭을 적습니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` · `style.css` · `app.js` | 정리기 화면 |
| `clean.js` | 정리 엔진. `rules/*.json`의 «작업»을 그대로 실행합니다 |
| `lib/` | 엑셀을 읽고 쓰는 SheetJS 0.20.3과 라이선스(Apache-2.0). 다른 사이트에서 불러오지 않습니다 |
| `rules/목록.json` | 처방 파일 목록. 처방 파일을 새로 만들면 여기에 이름을 더합니다 |
| `rules/입출금관리.json` | 입출금관리 처방. 처방마다 하는 일(do) · 이유(why) · 정한 사람(owner)이 있습니다 |
| `data/입출금관리.xlsx` | 시험용 엑셀. 지어낸 가상 고객사 데이터입니다 |
